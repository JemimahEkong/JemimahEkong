# Hey, I'm Jemmy 👋

### Developer • Technical Writer • Open Source Contributor

I'm a developer and technical writer who enjoys building, contributing, and documenting things in public.

My interests sit at the intersection of **software development, blockchain, AI, and open source**. I enjoy understanding how systems work under the hood, contributing to real codebases, and turning complex technical concepts into documentation that people can actually understand.


## 🧑🏽‍💻 What I Do

-  Build and contribute to open-source projects
-  Write and work with **Rust** and **Solidity**
-  Build with **JavaScript, Solidity, HTML, CSS, and Tailwind CSS**
-  Explore **blockchain, Web3, smart contracts, and decentralized systems**
-  Build and experiment with **AI-powered applications**
-  Write technical documentation, guides, and developer content
-  Explore unfamiliar codebases and turn what I learn into useful contributions
-  Use Git and GitHub for version control, collaboration, and open-source development


##  What I've Been Building & Contributing To

###  Blockchain & Web3

I've contributed to projects within the **Stellar/Soroban ecosystem** and explored smart contracts, blockchain infrastructure, developer tooling, and decentralized applications.

I've also worked with technologies and projects across **Bitcoin, Lightning, Solana, and EVM ecosystems**, giving me exposure to different approaches to decentralized infrastructure.

###  Rust & Smart Contracts

Rust is one of the technologies I'm intentionally investing in.

I've worked on Rust-based open-source projects involving blockchain and infrastructure, while continuing to deepen my understanding of the language.

I've also worked and still exploring **Solidity and EVM-based development**, particularly smart contracts and decentralized applications.

###  AI

I'm interested in practical applications of AI rather than AI for the sake of AI.

I've explored AI agents and AI-powered tools, including building an **AI agent during a Bitcoin hackathon** and experimenting with applications that combine AI with blockchain and developer infrastructure.

##  Technical Writing

Technical writing sits alongside my development work.

I enjoy taking something complicated, understanding it properly, and explaining it simply.

I've worked on:

- README documentation
- Developer guides
- API documentation
- Contribution guides
- Technical explanations
- Code documentation
- Open-source issue documentation
- Tutorials and implementation notes

I believe good documentation isn't an afterthought.

**If people can't understand how to use, contribute to, or build on software, the software isn't reaching its full potential.**


##  Open Source

Open source is a big part of how I learn.

Rather than only building projects privately, I like getting into existing repositories, reading unfamiliar code, finding gaps, fixing things, and contributing back.

Some of my work has involved:

- Implementing features and fixes
- Writing and improving documentation
- Working through GitHub issues
- Understanding existing architectures
- Writing tests
- Reviewing implementation details
- Collaborating through pull requests

I believe one of the best ways to become a better developer is to **read code you didn't write.**
